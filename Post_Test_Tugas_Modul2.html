F. Post-Test

1. Apa fungsi dari git merge dalam workflow Git?

Menggabungkan perubahan dari satu branch ke branch lain, misalnya hasil kerja di branch fitur digabung ke branch main, sehingga riwayat dan isi file dari kedua branch menyatu.

2. Jelaskan cara mengatasi konflik saat melakukan merge!

Konflik terjadi saat dua branch mengubah baris yang sama pada file yang sama, sehingga Git tidak bisa memilih sendiri. Langkahnya:

  1. Jalankan git status untuk melihat file yang konflik.
  2. Buka file tersebut. Bagian yang konflik ditandai <<<<<<<, =======, dan >>>>>>>.
  3. Pilih isi yang dipakai (salah satu atau gabungan), lalu hapus ketiga tanda tadi.
  4. Simpan file, lalu jalankan git add nama_file.
  5. Jalankan git commit untuk menyelesaikan merge.

3. Tulis langkah-langkah untuk menambahkan file baru ke repository Git dan melakukan commit.

  1. Buat atau salin file ke folder proyek.
  2. git status untuk memastikan file terdeteksi (untracked).
  3. git add nama_file untuk memasukkannya ke staging area.
  4. git commit -m "pesan commit" untuk merekam perubahan.
  5. git push kalau ingin mengirimnya ke GitHub.

2. Workflow Git dengan branch fitur baru dan integrasi ke branch utama

Alur: main (stabil) → buat branch fitur → commit di branch fitur → merge ke main → push → hapus branch fitur.

git checkout -b fitur-readme
echo "# Profil Keluarga" > README.md
git add README.md
git commit -m "Add README"
git checkout main
git merge fitur-readme
git push origin main
git branch -d fitur-readme
git log --oneline --graph
